## 一 · 步骤条：第①步时后面两步必须是灰的

**文件**：`store/useStore.ts`、`components/StepBar.tsx`

### 1.1 病因

store 的初始 `project` 是 `seedProject`（已入库 + 有分镜 + 提示词），`replayDemo` 也只把相位复位、不换 project。
于是空态 → 上传弹窗 → 整理动效这一路，`StepBar` 拿着一个「全做完了」的 project 算 `done`，② ③ 自然是 ✓。

### 1.2 改法（两刀都要）

**刀一 · 起点必须是空项目。** `data/seed.ts` 加：

```ts
/** 进站起点：一个什么都没有的项目。episodes / scenes / shots / assets 全空，未入库。 */
export const emptyProject: Project = {
  ...seedProject, episodes: [], scenes: {}, shots: {}, assets: {}, libraryCommittedAt: null,
}
```

store 初始 `project: structuredClone(emptyProject)`、`promptStates: {}`；`replayDemo` 同样把 `project` 换成 `emptyProject`、`promptStates` / `promptEdited` 清空。
`tests/` 里若有断言依赖「一开机就是 seedProject」，在那条测试开头 `useStore.setState({ project: structuredClone(seedProject) })` 即可——最小修改。

**刀二 · ✓ 必须按顺序。** `StepBar`：

```ts
const done = {
  1: extracted,
  2: extracted && committed,
  3: extracted && committed && allReady,
}
// 当前步之后的步，除非 done，一律 disabled 灰显（不是 jumpable 蓝）
```

### 1.3 验收

重新演示 → 上传 → 动效 → 整理剧本页：② ③ 都是灰的数字。提取完到②：① ✓、② 当前、③ 灰。拆完到③：①② ✓、③ 当前。

## 二 · 演示原文：假设用户的剧本什么结构都没有

**文件**：`data/rawScripts.ts`（已就绪）、`data/seed.ts`、`data/seedEpisode2.ts`、`pages/EpisodeOrganize.tsx`、`pages/AssetConfirm.tsx`

### 2.1 口径

用户上传的就是一大段散文，没有「第一集」「第一场」「时间 / 地点」这些标记。步骤① 只把它切成集，**页面上不许再出现任何小标题、场头、`§` 行**。
段落只保留作者自己的换行。

### 2.2 接线

- `seed.ts`：`e1.rawText = joinChunks(EP1_CHUNKS)`；`scene1/2/3` 的 `rawText` 分别 = `EP1_CHUNKS[0] / [1] / [2]`（把原来「周六 中午 12:00 · 客厅沙发\n\n…」那段字面量整个替换掉）。删掉 `buildEpisodeRawText` 和 `§` 那套逻辑。
- `seedEpisode2.ts`：`ep2Episode.rawText = joinChunks(EP2_CHUNKS)`；`ep2s1 / ep2s2` 的 `rawText` = `EP2_CHUNKS[0] / [1]`。
- `wordCount` 维持演示口径 4 800 / 3 600 不动（正文比以前长了一倍多，但仍不到真实一集的量；演示数字自圆其说即可）。
- `EpisodeOrganize` 的 `EpisodeBody` 和 `AssetConfirm` 左栏：删掉 `§ ` 小标题分支，`rawText.split('\n')` 过滤空行后每行一个 `<p>`。
- `ScriptPanel`（步骤③ 本场剧本）如果也在识别首行场头，一并删。

### 2.3 集标签

集块标题写成 **`第 1 集`**（主标签，15px 600），AI 起的标题（「外卖与尊严」）作为灰色副标签跟在后面：

```
▾  第 1 集   外卖与尊严   🔒 / 新增                         4,800 字   ⋯
```

步骤② 左栏每集块标题同样 `第 1 集 · 外卖与尊严`。「重命名」改的是副标签。

## 三 · 整理剧本页放宽（照小云雀截屏）

**文件**：`pages/EpisodeOrganize.tsx` + `.module.css`

```
                                                                             ← 上方留白 32px
   共 1 集                                                        [⋯]      ← 28px / 600
   当前已整理 1 集 · 4,800 字                                                ← 13px 灰

   ┌───────────────────────────────────────────────────────────────────┐   ← 一张卡：max-width 1080，居中，
   │                                                                   │      padding 40px 56px，圆角 var(--rlg)，
   │   ▾  第 1 集   外卖与尊严   🔒                       4,800 字  ⋯   │      背景 var(--bg1)
   │                                                                   │
   │      苏可蜷在客厅的沙发里，身上还是那件穿了三天的宽松连帽卫衣……      │   ← 正文 14.5px / line-height 1.95
   │                                                                   │      段间距 18px，左缩进与集标题对齐+28px
   │      三分钟后。苏可贴着墙根……                                       │
   │                                                                   │
   │   ▸  第 2 集   视频求生   新增                       3,600 字  ⋯   │   ← 集与集之间 28px 间距 + 1px 分隔线
   └───────────────────────────────────────────────────────────────────┘

                    ┌──────────────────────────────────────────────┐
                    │ ● 剧本内容整理完毕，将进行剧本资产拆解  [资产提取 · ✦40] │   ← 悬浮胶囊，见 3.2
                    └──────────────────────────────────────────────┘

### 3.1 尺寸

- 页面本身 `overflow-y: auto`，整页滚，不再是「列表区自己滚」。
- 卡片 `max-width: 1080px; margin: 0 auto; padding: 40px 56px`；集块标题行 `padding: 14px 0`；集标签 15px/600；正文 14.5px、`line-height: 1.95`、`color: var(--t2)`；段落 `margin: 0 0 18px`。
- 异常提示条放在卡片上方、同宽。

### 3.2 页脚改成悬浮胶囊

- 固定在视口底部居中（`position: sticky; bottom: 24px`，宽度 `fit-content`，最小 520px），深色底 `var(--panel)`、圆角 999、阴影 `0 12px 32px rgb(0 0 0 / .45)`。
- 左：绿点 + 文案；右：主按钮。文案与按钮：
  - 未入库有草稿：`剧本内容整理完毕，将进行剧本资产拆解` ｜ `资产提取 · ✦40`
  - 已入库有草稿：`新增 1 集，将只对新集提取资产` ｜ `资产提取 · ✦32`
  - **没有草稿：整个胶囊不渲染。** 删掉 `进入下一步 →` 那个状态——这一页看完了就点步骤条，不需要按钮催。
- 价格小字「按字数计费 · ✦8 / 千字」放在按钮 title 里（hover 可见），不占胶囊空间。

## 五 · 分镜页：去 tab、「主要内容」带资产高亮

**文件**：`pages/ScriptAnalysis.tsx`、`components/TabBar.tsx`（删）、`components/AssetList.tsx`（不再从此页引用）、`components/EntityText.tsx` + `.module.css`、`components/AtMentionPicker.tsx`

### 5.1 去 tab

- 顶部「分镜脚本 / 角色 / 服装 / 场景 / 道具」那排 tab 整个删掉：分镜页就是一张大表。`TabBar` 组件删除；`AssetList` 在分析阶段不再有入口（项目资产库那页自己有）。
- `activeTab` 相关分支全删：工具栏只剩 `导出分镜脚本`；`isAssetTab` / `assetSort` / `导出资产表` / 排序下拉一并删。
- store 的 `activeTab` 字段和 `setTab` 可以留着（步骤② 的四个分类 tab 还在用）。

### 5.2 「主要内容」里的资产名静态高亮

现在 `EntityText variant="link"` 是「静态零色，hover 才亮」——这条决策推翻。用户 @ 插进去的资产名，显示时就该看得出它是资产。

- `EntityText` 的 link 变体：静态上**类目色**（`KIND_DOT[asset.kind]`，和左侧「本场剧本」原文面板一个口径），字重不变，下方 1px 同色 40% 下划线；hover 仍然点亮「出场的人和物」里对应那一项（现有联动不动）。
- `look` 不进词表的规则不变（正文里写的是角色名）。
- 顺手：`@` 选择器（`AtMentionPicker`）插入后，编辑框里那个词也用同一套色（编辑态的 textarea 背板层用 `EntityText variant="mark"` 已经在做，把 mark 的单色换成类目色即可）。
- `EntityText.tsx` 头注里「静态零色 / 灰阶区」那段解释改成一句：**「@ 得进来的东西，看得出来是什么」**。

```
