### 3.4 造型：只能从已有服装里选，不能在这里新建

现在角色行有「N 套造型 ⌄」+「＋ 服装」，「＋ 服装」的下拉还能输名字新建——歧义在于用户不知道这是在建服装还是建造型。改成：

- 角色行**删掉「＋ 服装」**，只留 `N 套造型 ⌄`。
- 展开后，造型子行列表末尾加一条虚线子行：

```
苏可                                  【生成规格】角色素模基础…        待入库    🗑
  ├─ 苏可 · 宽松连帽卫衣               苏可素模 + 宽松连帽卫衣的融合…   待入库    🗑
  └─ ＋ 增加一套造型                                                          ← 虚线边框、var(--t3)，hover 变实
```

- 点「＋ 增加一套造型」弹一个小下拉（复用现有 `CostumePicker` 的壳）：**只列出服装 tab 里已有的服装**（候选 + 已入库，排除本角色已挂的），选一件即新建造型。**删掉输入框「新建服装…」和「新建」按钮。**
- 下拉底部固定一行灰链接：`没有合适的服装？去「服装」新增 →`，点了 `setTab('costume')` 并关闭下拉。可选服装为空时，下拉只显示这一行。
- 造型子行右侧那个 `⇄` 换服装下拉**删掉**（`swapCandidateCostume` store 动作留着不用）。子行只剩 🗑（解除这套造型）。

## 五 · 步骤③：左侧目录支持「全剧 / 本集 / 本场」三种视图，默认全剧

**文件**：`store/useStore.ts`、`components/EpisodeTree.tsx` + `.module.css`、`components/Storyboard.tsx` + `.module.css`、`components/ScriptPanel.tsx`、`pages/ScriptAnalysis.tsx`

### 5.1 为什么

拆完 25 镜只能一场一场看，用户第一眼想看的是「整部剧拆成了什么样」。默认给全剧，想聚焦再点集 / 场。

### 5.2 状态

```ts
export type ViewScope =
  | { kind: 'project' }
  | { kind: 'episode'; episodeId: string }
  | { kind: 'scene'; sceneId: string }

viewScope: ViewScope            // UI 态；startSplit / confirmIncremental 跑完置 { kind: 'project' }
setViewScope: (v: ViewScope) => void
```

`selectedSceneId` 保留：它现在的含义是「本场剧本面板 / 场级设定抽屉正对着哪一场」。`setViewScope` 为 scene 时同步设 `selectedSceneId`；为 episode 时设为该集第一场；为 project 时设为全剧第一场。

### 5.3 左侧目录

```
  ┌ 集 · 场 ─────────────────────┐
  │ 全部镜头            25 镜 · 118s │   ← 新增的顶行，粗体；选中态同现在的场行 .on
  │                                 │
  │ 第 1 集 · 外卖与尊严        ⋯   │   ← 集标题行变成可点：点了 = 本集视图（选中态）
  │   1  客厅沙发        8 镜 · 38s │   ← 场行照旧 = 本场视图
  │   2  玄关            6 镜 · 30s │
  │   3  餐桌           11 镜 · 50s │
  │ 第 2 集 · 视频求生          ⋯   │
  │   1  客厅沙发 …                 │
  └─────────────────────────────────┘
```

- 三种行只有一个是选中态（按 `viewScope` 判）。
- 集标题行的 ⋯ 菜单（重拆本集 / 删除本集）不变，点标题文字才切视图；hover 整行有底色。

### 5.4 表格区

`Storyboard` 现在接一个 `scene`。改成接 `scenes: Scene[]`（按顺序），内部**每场一个区块**纵向排列：

```
  ── 第 1 集 · 第 1 场 · 客厅沙发 ─────────────── 8 镜 · 38 秒 ── [场级设定] [重拆本场] ──   ← 场区块头，sticky 在表格顶部
     [场时间轴：只在「本场」视图显示；全剧 / 本集视图不渲染时间轴，省高度]
     ┌ 镜号·时长 │ 景别 │ 镜头设计 │ 出场的人和物 │ 主要内容 │ … ┐    ← 列头只在第一个区块渲染一次，列宽三个区块共享
     │ 1  4s …                                                  │
     │ …                                                        │
     └ ＋ 在末尾插入一镜 ────────────────────────────────────────┘
  ── 第 1 集 · 第 2 场 · 玄关 ──────────────────── 6 镜 · 30 秒 ──
     …
```

- 全剧视图 = 所有集所有场；本集视图 = 该集各场；本场视图 = 一场（就是现状，加上时间轴）。
- 列宽拖拽的 `widths` state 提到 `Storyboard` 顶层一份，所有区块共用。
- 镜号仍按场内编号（1、2、3…），区块头已经交代了是哪一场。
- 点区块头 → `setViewScope({ kind: 'scene', sceneId })`（聚焦到这一场）。区块头右侧两个小按钮：`场级设定`（打开现有抽屉，先 `selectScene`）、`重拆本场`（现有弹窗）。**场 ⋯ 菜单里的重拆入口保留不动**，这里只是多一个顺手的口。
- hover 联动（主要内容 ↔ 出场的人和物）按 shotId 走，跨场无影响。
- 「在此插入一镜」行热区每个区块各自一套。

### 5.5 本场剧本面板

`ScriptPanel` 跟随 `viewScope`：project / episode 视图时依次渲染范围内每场的原文（每场一个报头 + 正文，同现有排版）；scene 视图只渲染那一场。面板标题「本场剧本」按视图改成「全剧剧本 / 本集剧本 / 本场剧本」。

### 5.6 页脚重排（同时落实「生成全部提示词」「去资产库生图弱化在最右」）

```
  全剧 1 集 · 3 场 · 25 镜 · 约 118 秒     提示词 ▮▮▮▯▯▯▯▯ 3 / 25 · 2 待更新      [生成全部提示词 · ✦132]  [去资产库生图 →]
  全剧 1 集 · 3 场 · 25 镜 · 约 118 秒     提示词 ▮▮▮▮▮▮▮▮ 25 / 25 已就绪                                [去资产库生图 →]
```

- 「N 场 N 个镜头待生成提示词（含 N 镜内容已改动待更新）→」那一长串换成**一个 120px 的细进度条 + `3 / 25`**；有 stale 时后面跟 `· 2 待更新`（琥珀色）。整组可点，点了 = 打开全剧范围的生成弹窗。
- **`生成全部提示词 · ✦N`**：主按钮，`N = costShotPrompts(needIds)`。点击打开 `ConfirmPromptDialog`，`defaultScope='project'`（弹窗里仍可缩小范围）。生成中显示「生成中…」disabled。全部就绪后这个按钮**消失**。
- **`去资产库生图 →`**：永远在最右。未就绪时是普通（ghost）按钮，点了弹 v2.6 的 `GoVisualDialog` 软提醒；全就绪后变成主按钮样式（亮），点了直接 `setStage('visual')`。v2.6 那个文字链接「先去资产库生图 →」删掉，由这个按钮接管。
